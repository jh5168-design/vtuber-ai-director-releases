Step 01 · Intelligence

Connect the model that does the directing.

VTuber AI Director speaks to any OpenAI-compatible endpoint. A local service is the most private starting point; a cloud provider works when you need more capacity.

Recommended · LM Studio

Load an instruction-capable model, open the Developer tab, and start the local server on port 1234.

Service URL http://localhost:1234/v1 API key leave blank Model select the loaded model
OllamaUse http://localhost:11434/v1 and the model name you pulled.
Cloud providerEnter the compatible base URL, model name, and provider API key.
✦
Test before continuing

Open Settings → AI model service, choose a preset, then use Test connection. The app reports the model response and structured-output mode.

Step 02 · Voice

Let the director follow your performance.

Use Local Whisper for speech tracking that stays on your computer. The first run downloads the recognition model; future runs reuse it.

Configure speech input

In Live Stream or Live Rehearsal, work through these checks in order.

1Choose Local Whisper (recommended, offline) as the recognition engine.
2Select Chinese, Japanese, English, or automatic language detection.
3Click Allow access and refresh microphones, then choose the correct input.
4Run the five-second input test. Confirm the level moves and the spoken sample is transcribed.
♫
Browser recognition is optional

It depends on browser and OS support and may send audio to the browser vendor. Local Whisper is the predictable desktop path.

Step 03 · Persona

Teach the director who is on camera.

A character profile is more than a prompt. It is the identity boundary for memories, viewer relationships, language, humor, and behavior.

A useful first profile

Start with a small, concrete definition. You can refine it after hearing a rehearsal.

Name Astra Vale Occupation Night-shift archivist Traits Observant, warm, quietly mischievous Speaking tone Conversational; short vivid metaphors Would say "Let’s open that file." Never say Invented personal facts about viewers
Write positive directionShow the desired rhythm and vocabulary with example lines.
Set hard boundariesList topics, claims, and behaviors the character must avoid.
◈
Memory is character-scoped

A stream using Astra never reads another character’s memories or viewer profiles. Rehearsal and production are also separate environments.

Step 04 · Rehearse

Run one safe, observable rehearsal.

Start with low simulated audience activity. Read naturally, deliberately improvise once, and watch how the director updates only the future buffer.

Five-minute acceptance run

✓Select your new character and leave the optional rehearsal instructions blank.
✓Set simulated audience activity to Low and start the rehearsal.
✓Read several sentences. Confirm the teleprompter highlight advances with speech, not elapsed time.
✓Say a new thought that is not in the script. Confirm the director marks improvisation and adapts upcoming dialogue.
✓Stop the rehearsal. Open Memory Studio and confirm the entry remains under the Rehearsal environment.
●
You are ready for production when…

Audio is stable, model generation finishes before your ready buffer empties, and the character sounds right when you speak the lines aloud.
