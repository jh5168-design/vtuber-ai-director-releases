INSTALLATION

From download to rehearsal.

Install the app, choose a model connection, then verify audio before starting your first rehearsal.

Install the desktop app

Open the DMG on macOS or run the NSIS installer on Windows. Keep the app in a user-writable location.

Connect a model

Use local LM Studio or Ollama, or enter an OpenAI-compatible service URL and optional API key.

Test speech input

Allow microphone access, select Local Whisper, and run the five-second input test before rehearsal.
