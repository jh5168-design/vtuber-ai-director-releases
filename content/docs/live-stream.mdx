---
title: Live Stream
description: Brief the director in plain language, review how it understood you, then start Full Auto.
---

Open **Live Stream** to reach **Pre-Stream Setup**. The director uses only the selected character's memories for the whole session.

<Steps>
<Step>

### Choose a character and speech input

Select the character, the microphone, and the recognition engine. Run the **Audio input test** if anything about your setup changed since the last stream.

</Step>
<Step>

### Write session instructions

Describe the stream the way you would brief a co-host: the format, atmosphere, restrictions, how to treat chat, and any capabilities the session needs. Ordinary language is fine.

</Step>
<Step>

### Add a manuscript (optional)

Attach a TXT or Markdown manuscript to give the director reference content. The app remembers where you stopped, so you can resume from the same position.

</Step>
<Step>

### Review the director policy

Select **Interpret instructions** to preview how the director understood your note. Your original instructions are preserved.

</Step>
<Step>

### Start Full Auto

Select **Start Full Auto** when the policy matches what you intended. To connect a Bilibili room, set up [Bilibili Open Live](/docs/bilibili) first.

</Step>
</Steps>

<Callout type="idea" title="Rehearse the brief first">
  The same instructions work in [Live Rehearsal](/docs/live-rehearsal). Try a new format there before you take it to a real audience.
</Callout>
