---
title: Character Studio
description: A character sets how the director writes and which memories it is allowed to read.
---

Every character is two things at once: a voice and a boundary. The director writes in the character's style, and it reads only the memories, viewer profiles, callbacks, and sessions recorded for that character.

## Profile fields

| Field                                      | What to write                                                              |
| ------------------------------------------ | -------------------------------------------------------------------------- |
| Character name, Species, Occupation        | Who is on camera, in a few words.                                          |
| Description, Background, Worldbuilding     | The history and setting the character draws on.                            |
| Personality traits                         | Three or four concrete traits, not a list of adjectives.                   |
| Speaking tone                              | Rhythm, register, and habits of speech.                                    |
| Typical phrases and expressions            | Lines the character would really say.                                      |
| Forbidden speech and behavioral boundaries | What the character must never claim, reveal, or joke about.                |
| Example dialogue (one per line)            | Short, speakable lines. These teach the director more than any adjective. |

## Write lines you can perform

Short example lines that sound natural out loud are more useful than abstract descriptions. Pair them with explicit boundaries, then refine the profile after you hear the character in a [rehearsal](/docs/live-rehearsal).

```txt title="A useful first profile"
Character name    Astra Vale
Occupation        Night-shift archivist
Personality       Observant, warm, quietly mischievous
Speaking tone     Conversational; short, vivid metaphors
Typical phrases   "Let's open that file."
Boundaries        Never invent personal facts about viewers
```

<Callout title="Switching characters switches everything">
  Memories, viewer profiles, callbacks, and sessions are always queried with the selected character's ID. A stream using one character never reads another character's history.
</Callout>

Use **Duplicate character** to start a variation without retyping the profile, and **Save profile** to keep your changes.
