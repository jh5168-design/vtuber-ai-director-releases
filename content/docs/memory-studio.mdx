---
title: Memory Studio
description: Review what the director remembers, kept separately for live streams and rehearsals.
---

Memory Studio has two environments, **Live stream** and **Live rehearsal**. Each memory belongs to exactly one character and one environment. Switch between **Memories** and **Viewer Profiles** to review either, and use **Add** to record a confirmed memory by hand.

## What each memory records

| Field           | Meaning                                                                      |
| --------------- | ---------------------------------------------------------------------------- |
| Source type     | Where the memory came from, such as a memory you confirmed yourself.         |
| Actually spoken | Whether the line was said on stream, not only generated.                     |
| Importance      | A score from 0 to 1 for how much weight the memory carries.                  |
| Confidence      | A score from 0 to 1 for how certain the memory is.                           |
| Callback usage  | How many times the director has brought the memory back into conversation.  |

## Move a rehearsal memory to live

Rehearsal memories never move into live-stream memory on their own. To keep one, select it, choose **Transfer to live memory**, and confirm. The transfer clears its viewer and session association, so a simulated viewer never becomes a real one.
